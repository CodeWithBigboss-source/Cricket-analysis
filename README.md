# 🏏 Cricket Data Analysis Project

## 📌 Overview
This project analyzes cricket match data to extract useful insights such as:
- Top winning teams
- Player of the match statistics
- Toss impact on match results

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib

## 📊 Key Insights
- Mumbai Indians is the most successful team
- AB de Villiers has the most Player of the Match awards
- Toss winner wins match many times

## 📈 Visualizations
- Top teams by wins
- Top players by awards

## 🚀 How to Run
1. Install libraries:
   pip install pandas matplotlib

2. Run:
   python analysis.py
